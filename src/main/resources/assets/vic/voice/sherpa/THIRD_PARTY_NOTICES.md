# Bundled Sherpa-ONNX Voice

The bundled `en_US-libritts_r-medium` voice model is from the Piper Voices project and is trained on the LibriTTS-R dataset by Koizumi et al. (2023). The model card identifies the dataset license as Creative Commons Attribution 4.0 International (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/ . Dataset information and citation: https://openslr.org/141/ . Model source: https://huggingface.co/rhasspy/piper-voices/tree/main/en/en_US/libritts_r/medium . The model is redistributed unchanged.

The bundled English lexicon is provided by the Sherpa-ONNX project: https://github.com/k2-fsa/sherpa-onnx . The Sherpa-ONNX Java API and native runtime are licensed under Apache License 2.0: https://github.com/k2-fsa/sherpa-onnx/blob/master/LICENSE . The model files are redistributed with attribution under CC BY 4.0.
